# TypeNova

A complete, original typing-learning and productivity platform for web and desktop.

## Product direction
- Web: Next.js + React + TypeScript
- Desktop: Tauri 2, Windows first
- UI: Tailwind CSS + shadcn/ui
- Core: framework-independent TypeScript typing engine
- Backend: PostgreSQL + Prisma + versioned API
- Authentication: Auth.js
- Quality: Vitest, Playwright, accessibility and CI

## Modules
Dashboard, Learn, Practice, Speed Tests, Smart Practice, Audio Typing, Vocabulary, Games, Code Typing, Analytics, Replay, Certificates, Leaderboards, Profile and offline desktop practice.

## Principles
- Calculate metrics from real keystrokes; never fabricate results.
- Support guest practice and account-based progress sync.
- Share domain logic between web and desktop.
- Make offline behavior and synchronization explicit.
- Build original UX, content and assets; do not copy proprietary implementations.
- Do not claim untested functionality works.
